# Tareas

Lo que decidimos hacer y todavía no está hecho. Un archivo por tarea, con el
mismo formato que `wishlist/`: qué, estado, y el porqué con lo medido.

La diferencia con las otras carpetas: `wishlist/` es lo que nos gustaría,
`decisiones/` lo que ya se decidió y sigue valiendo, `divergencias/` dónde la
ROM difiere de RM2k, y `ESTADO.md` lo que está a medias **ahora**.

**Si una tarea resulta demasiado compleja o cara, se mueve a `wishlist/`** y se
le escribe por qué. Es un movimiento de archivo, no una discusión.
